# Lebanon Tourism Explorer

## Overview

This Streamlit application explores tourism characteristics across towns and administrative areas in Lebanon.

The application uses interactive Plotly visualizations to examine:

- Tourism Index across towns
- Tourism infrastructure in selected towns
- Hotels
- Restaurants
- Cafes
- Guest houses

## Interactive Features

### Administrative Area Selection

Users can select an administrative area to focus the analysis on a specific geographic area.

### Linked Town Selection

The available towns change according to the selected administrative area. This allows users to drill down from an administrative area to a specific town.

## Technologies

- Python
- Pandas
- Plotly
- Streamlit
